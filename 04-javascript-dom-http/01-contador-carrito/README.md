# 01 — Contador de carrito

Completa `app.js` para que los botones `+` y `-` actualicen la cantidad y el total.

## Reglas

- La cantidad nunca puede ser negativa.
- Precio unitario: 29,99 €.
- El botón `-` debe quedar deshabilitado cuando la cantidad sea 0.
- No recargues la página.
- El DOM debe reflejar siempre el estado actual.

## Se evalúa

Selección de elementos, listeners, estado mínimo y actualización del DOM.
