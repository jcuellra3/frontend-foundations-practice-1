# 02 — Filtrar una tabla

Haz que el campo de búsqueda filtre las filas de la tabla por nombre o ciudad mientras el usuario escribe.

## Requisitos

- Búsqueda case-insensitive.
- Ignora espacios al principio y al final.
- Si no hay coincidencias, muestra el mensaje “Sin resultados”.
- No reconstruyas toda la página con `innerHTML` en cada tecla.
- El botón “Limpiar” debe restaurar todo.

## Extra

Añade un contador de resultados visible.
