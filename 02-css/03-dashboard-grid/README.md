# 03 — Dashboard con CSS Grid

Construye un dashboard responsive a partir del HTML dado.

## Layout esperado

- cabecera a todo el ancho;
- navegación lateral en escritorio;
- área principal con tarjetas KPI;
- bloque de actividad reciente;
- en móvil, una sola columna sin scroll horizontal.

## Practica

- CSS Grid;
- `minmax()`;
- `auto-fit`/`auto-fill`;
- áreas o columnas de grid;
- combinación Grid + Flexbox.

## Restricciones

- No uses Bootstrap ni frameworks CSS.
- Evita anchuras mágicas para cada breakpoint.
- Las tarjetas deben adaptarse al espacio disponible.
