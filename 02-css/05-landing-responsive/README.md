# 05 — Landing responsive

Ejercicio final de CSS. Convierte el HTML entregado en una landing responsive completa.

## Debe incluir visualmente

- hero;
- lista de beneficios;
- grid de planes;
- llamada a la acción;
- footer.

## Objetivo

Resolver una página real usando CSS moderno sin framework.

## Se evaluará

- mobile-first razonable;
- composición con Flex/Grid;
- ausencia de desbordamientos;
- escala tipográfica coherente;
- espacios consistentes;
- foco visible;
- uso moderado de media queries;
- código CSS fácil de mantener.

## Extra

Si terminas pronto, adapta colores con `prefers-color-scheme` y reduce animaciones con `prefers-reduced-motion` si has añadido alguna.
