# 01 — Tarjeta de producto

Partiendo del HTML entregado, crea una tarjeta de producto sin modificar su estructura salvo que detectes un problema semántico real.

## Debe practicar

- box model;
- selectores;
- herencia y cascada;
- tipografía;
- `border`, `padding`, `margin`;
- estados `:hover` y `:focus-visible`;
- variables CSS.

## Requisitos

- Define tokens básicos en `:root` para colores, espacios y radio.
- El botón debe tener un foco visible.
- No uses `!important`.
- No uses estilos inline.
- La tarjeta debe seguir siendo usable con zoom del navegador.
