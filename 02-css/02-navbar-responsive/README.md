# 02 — Navegación responsive

Da estilo a la navegación proporcionada.

## Objetivo

En escritorio, logo y enlaces deben compartir una fila. En pantallas pequeñas, el contenido debe poder reorganizarse sin desbordamientos horizontales.

## Practica

- Flexbox;
- `gap`;
- distribución y alineación;
- media queries;
- unidades relativas;
- estados interactivos.

## Requisitos

- No fijes alturas rígidas para hacer que “cuadre”.
- No ocultes enlaces importantes en móvil.
- No uses JavaScript.
- Evita media queries innecesarias: resuelve primero todo lo posible con layout flexible.
