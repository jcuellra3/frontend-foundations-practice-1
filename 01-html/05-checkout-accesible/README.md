# 05 — Mini checkout accesible

Ejercicio final de HTML. Construye la estructura de una pantalla de checkout sin CSS ni JavaScript.

## Secciones

- cabecera de la tienda;
- progreso del proceso (carrito → envío → pago);
- resumen de productos;
- formulario de dirección de envío;
- método de envío;
- resumen económico;
- botón final de compra;
- información legal o ayuda.

## Objetivo

Demostrar que puedes estructurar una interfaz real usando HTML semántico y controles nativos antes de pensar en estilos o frameworks.

## Criterios de aceptación

- Orden de lectura lógico.
- Formularios correctamente etiquetados.
- Las agrupaciones de controles tienen significado.
- Botones y enlaces se usan según su propósito real.
- No existen elementos interactivos simulados con `div` o `span`.
