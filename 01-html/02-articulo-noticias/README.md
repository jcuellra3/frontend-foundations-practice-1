# 02 — Artículo de noticias

Maqueta únicamente con HTML la estructura de un artículo periodístico.

## Incluye

- breadcrumb o ruta de navegación;
- título, subtítulo, autor y fecha;
- imagen con texto alternativo y pie de foto;
- cuerpo dividido en varias secciones;
- una cita destacada;
- enlaces relacionados;
- información del autor al final.

## Debes pensar

- cuándo usar `article`, `section`, `aside`, `figure`, `figcaption`, `time`, `blockquote`;
- qué información debe estar dentro del `article` y qué puede ser complementaria;
- cómo hacer que la fecha tenga valor legible por máquina.

## Criterios de aceptación

- La estructura tiene sentido sin CSS.
- `figure` y `figcaption` se utilizan correctamente.
- La fecha usa `time` con `datetime`.
- La cita no está hecha con comillas y un `p` sin más.
