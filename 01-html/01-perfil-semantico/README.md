# 01 — Perfil profesional semántico

Construye una página de perfil profesional sin CSS y sin JavaScript.

## Debe contener

- cabecera con nombre, profesión y navegación interna;
- sección “Sobre mí”;
- sección de experiencia con al menos 2 trabajos;
- lista de habilidades;
- bloque de contacto;
- pie de página;
- al menos un enlace externo y uno interno.

## Restricciones

- No uses `div` salvo que puedas justificar que ninguna etiqueta semántica encaja mejor.
- La jerarquía de encabezados debe ser coherente.
- Los enlaces deben tener textos descriptivos.
- El documento debe tener `lang`, `title` y metadatos básicos.

## Criterios de aceptación

- El documento se entiende aunque no tenga estilos.
- Solo existe un `h1` principal.
- Las secciones importantes tienen encabezado.
- La navegación interna funciona.
- El HTML valida razonablemente y no hay etiquetas usadas solo por apariencia.
